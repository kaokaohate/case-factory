# Case Factory

**Make work worth showing.**

Case Factory is an AI creative-direction skill for producing original design showcases across brand identity, websites, app UI, design systems, contextual mockups, and editorial HTML case studies.

## What it does

- Develops a creative brief from an idea or supplied assets
- Explores distinct visual directions before selecting a design language
- Plans coherent brand, website, and app experiences
- Builds project-specific design rules and component showcases
- Assembles responsive, presentation-ready HTML case studies

## Editions

**Public repository:** Product overview, documentation, and future permission-cleared examples.

**Case Factory Pro 1.0 (engine v4.8):** Complete skill, references, agent configuration, and scripts, distributed separately through Gumroad. Purchase link will be added after launch.

## Requirements

A compatible AI agent environment with skill and file-generation support. Some workflows require an independently installed `frontend-design` companion; Stageshow is optional where supported. Exact output depends on host capabilities.
