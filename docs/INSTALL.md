# Installing Case Factory Pro

1. Purchase and download the official Case Factory Pro ZIP from Gumroad (link forthcoming).
2. Extract the archive. Keep the complete `case-factory/` directory intact, including `SKILL.md`, `references/`, `scripts/`, `agents/`, and `assets/`.
3. Copy the folder into the skill directory supported by your agent. For a Codex project, a typical path is `.agents/skills/case-factory/`; verify your host's current documentation.
4. Install the `frontend-design` companion independently if the workflow requires it; its license and availability are separate from Case Factory.
5. Invoke `$case-factory` if your agent supports skill invocation.

Compatibility has not yet been verified across all agent hosts. Do not assume every host supports every image, file, or HTML-generation capability.
