# Case Factory Pro

**Make work worth showing.**

Case Factory is a creative-direction skill that helps AI agents turn an idea or supplied design assets into a coherent, portfolio-ready design case study.

## Designed for

UX/UI designers, brand designers, creative technologists, and independent makers who need a stronger presentation of original work.

## Core workflow

1. Define the brief and compare three materially different visual directions.
2. Establish a project-specific design language.
3. Design connected brand, website, and app experiences.
4. Build a curated component and icon showcase.
5. Produce contextual mockups and an editorial responsive HTML case study.
6. Review layout, consistency, content and mobile quality.

## Pro package

Engine v4.8, SKILL.md, 13 reference guides, agent configuration, icon asset, and brief selection script.

## Before purchasing

- Requires a compatible AI agent with relevant file-generation tools.
- The frontend-design companion must be installed separately when required.
- Optional Stageshow integration is not bundled.
- Quality and available outputs depend on the agent environment.
