# Example prompts

Case Factory turns a creative brief into a portfolio-ready concept presentation.

## 1. Original brand + digital product

```
Use Case Factory in complete mode.
Create an original premium fitness brand with a distinctive visual identity,
a responsive official website, an app experience, a coherent design system,
and five or more realistic contextual mockups.
Deliver a single responsive HTML case study.
Label the work as an independent concept project.
```

## 2. App redesign

```
Use Case Factory to explore three visual directions for a productivity app redesign.
Prioritize information architecture, distinct real user tasks, and a connected
6–8-screen journey. Produce a project-specific design.md, responsive HTML
case study, and design system showcase. Do not invent user research findings.
```

## 3. Turn supplied assets into a showcase

```
Use Case Factory with my attached logo, screenshots, and brand assets.
Preserve my original design and distinguish any newly proposed additions.
Create a coherent editorial case study with readable UI, contextual mockups,
and clear credits. Ask only if an essential input is missing.
```

## Expected output

A complete-mode project targets original brand identity, 3–4 substantial website views, 6–8 app screens, 5–7 contextual mockup compositions, and a responsive HTML case study. Exact execution depends on available agent tools.

**Note:** These are prompts, not proof of tested outputs. Example screenshots will be added only after real end-to-end runs.
